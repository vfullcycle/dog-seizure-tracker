# 🐶 Dog Seizure Tracker — บันทึกอาการชักสุนัข

เครื่องมือฟรีสำหรับเจ้าของสุนัขที่เป็นโรคลมชัก ใช้บันทึกการชักแต่ละครั้ง แล้วสรุปเป็นกราฟและสถิติสำหรับติดตามแนวโน้มและใช้ประกอบการปรึกษาสัตวแพทย์

> ⚠ **คำเตือน**: เครื่องมือนี้ช่วยจดบันทึกและสรุปข้อมูลเท่านั้น ไม่ใช่เครื่องมือวินิจฉัย และไม่ทดแทนคำแนะนำของสัตวแพทย์ หากสุนัขชักนานเกิน 5 นาที หรือชักซ้ำหลายครั้งในวันเดียว ให้พาไปพบสัตวแพทย์ทันที

## วิธีใช้งาน

**แบบที่ 1 — เปิดผ่านเว็บ (ง่ายสุด):** เข้าลิงก์ → `https://vfullcycle.github.io/dog-seizure-tracker/`

**แบบที่ 2 — ดาวน์โหลดไปใช้เอง:** ดาวน์โหลดไฟล์ `index.html` แล้วดับเบิลคลิกเปิดใน browser ใช้งานได้แม้ไม่มีอินเทอร์เน็ต (offline)

เปิดครั้งแรก แนะนำกด **"ดูตัวอย่างด้วยข้อมูลสมมติ"** เพื่อเห็นภาพรวมความสามารถทั้งหมดก่อน

## ความสามารถ

- บันทึกการชัก: วัน–เวลา, ระยะเวลาชัก, ระยะฟื้นตัว, สิ่งกระตุ้น, ลักษณะการชัก, หมายเหตุ
- ตัวนับ "ปลอดอาการชักมาแล้วกี่วัน" และเส้นเวลาการชักทั้งหมด
- กราฟวิเคราะห์: แนวโน้มรายเดือน, ช่วงเวลาที่ชัก, การกระจายระยะเวลาชัก, ระยะห่างระหว่างการชัก, ความสัมพันธ์เวลาชัก–เวลาฟื้นตัว
- ตรวจจับวันชักซ้ำ (cluster days) และแจ้งเตือนอัตโนมัติเมื่อความถี่สูงผิดปกติจากค่าเฉลี่ยของสุนัขตัวนั้นเอง
- รองรับสุนัขหลายตัว แยกข้อมูลจากกัน
- บันทึกการรักษา: พบสัตวแพทย์, ปรับยา (เก็บชุดยาทุกครั้งที่เปลี่ยน), น้ำหนัก, ตรวจเลือด พร้อมคำแนะนำจากหมอ
- เส้นบอกจุดปรับยา/พบหมอบนกราฟแนวโน้ม เพื่อดูว่าการรักษาได้ผลไหม + กราฟน้ำหนักและ mg/kg
- กรองช่วงวันที่ / สำรอง–นำเข้าข้อมูล (JSON) / export CSV / พิมพ์สรุปสำหรับสัตวแพทย์ (ประวัติยาแสดงเต็มเสมอ)

## ความเป็นส่วนตัวของข้อมูล

**ข้อมูลทั้งหมดเก็บอยู่ในเครื่อง (browser) ของคุณเท่านั้น** ไม่มีการส่งข้อมูลขึ้น server ใดๆ — เปิดโค้ดตรวจสอบได้ทั้งไฟล์ ข้อแลกเปลี่ยนคือข้อมูลผูกกับ browser เครื่องนั้น การล้างข้อมูล browser จะลบบันทึกทั้งหมด **แนะนำกดปุ่ม "สำรองข้อมูล" เป็นระยะ**
